# Optimal convergence recovery for the 2D Coulomb problems

This experiment is stored in `optimal_rate/`.
It covers both 2D problems in the revised paper: one nucleus on `[-5,5]^2`
and two nuclei at `(-2,0),(2,0)` on `[-7,7] x [-5,5]`.

## Paper and release confirmation

The supplied manuscript was `paper_revised.tex`,
SHA256 `688a01de68d16bc32d27894e5b93ca93d55a60c04208fac1075c266664e62aaf`.
The inspected release commit was
`3698ab8e47c0cb9e48dc0ddd74660aff1116d892` (version 1.1.0).
Its stored 2D mesh sizes, Gamma_h and d_h reproduce the revised paper's
tables. The manuscript itself is supplied separately; there is no manuscript
TeX file at the release root.

The original `meshgen/gen_mesh_2d.py` explicitly clamps its mesh radius to
`max(r_rule, max(Lx,Ly)*1e-7)`. Its optimized perturbation estimate consequently
stagnates near 0.006 for one centre and 0.013 for two centres. This confirms
the explanation in the paper's Convergence subsection.

## Changes in this experiment

For p=4/3, the 2D patch contribution has power `rho^(2/p-1)=sqrt(rho)`.
The new family uses `rho=1e-6*h^4`, with no fixed radius floor. A Cartesian
core of this radius and geometrically spaced homothetic rectangular rings
preserve shape regularity. All nuclei are vertices. The two subdomain meshes
share exactly the same interface nodes. The tested levels are
`h=0.8,0.4,0.2,0.1`; each has `ceil(4/h)` subdivisions per half side.
The nominal h controls the mesh family; actual h_max is recorded separately.

The full Cartesian core is a comparison patch, which is a union of cells.
G1 is checked outside this expanded patch, and its radius satisfies the
required h^4 scaling. The direct patch/off-patch proof applies to any union
of cells containing the singular cells, as the release's perturbation code
also states. The optimized patch can be smaller than the full core.
This expanded-patch formulation should be stated explicitly if the new
experiments are incorporated into the paper; see `NOTES.md` for the precise
distinction from G1 applied outside only the nucleus star.

`stable_fem.jl` evaluates the same ECR space in translated, isotropically
scaled element coordinates. This avoids cancellation in quadratic moments
on tiny cells near the nonzero nuclei. Coulomb quadrature evaluates
displacements relative to each nucleus before interpolation.
The CECR reaction and shift retain the original cell-average projection;
P1 upper values integrate the original Coulomb potential.
The original release source files are unchanged.

`compute.jl` computes the first three eigenvalues, fixed-epsilon optimized
shift bounds (epsilon=0.55), fixed-shift bounds (sigma=12.5), both Neumann
and Dirichlet P1 upper values, residuals, perturbation components, and timings.
The optimized shift uses the release's radial Neumann-decoupling form bound
at epsilon-d_h, transferred to the cell-average potential.

## Reproduce

From the release root:

```sh
bash optimal_rate/run_all.sh
```

The script defaults to 16 Julia threads and one BLAS thread. Override with
`JULIA_BIN`, `JULIA_NUM_THREADS`, or `H_LEVELS` if needed. To run only one case:

```sh
bash optimal_rate/run_all.sh 2d_one_centre
```

Individual commands:

```sh
python3 optimal_rate/gen_mesh.py --case 2d_one_centre --h 0.2 --out optimal_rate/meshes/2d_one_centre_h0.2
julia -t 16 --project=. optimal_rate/compute.jl 2d_one_centre optimal_rate/meshes/2d_one_centre_h0.2 optimal_rate/results/2d_one_centre_h0.2.json
python3 optimal_rate/analyze.py
python3 optimal_rate/geometric_certificate.py
julia -t 16 --project=. optimal_rate/test_stable.jl
```

The mesh generator needs only the Python standard library. Analysis uses
NumPy and matplotlib, already available on hpc. The solver uses the release's
existing Julia project and VFEM dependency. `CECR_QUAD_CHECK=1` enables
higher-order quadrature comparisons for a computation.

## Results and interpretation

`convergence.md`, `summary.csv`, `convergence.csv`, and `tables.tex` are
generated by `analyze.py`. Meshes, raw computation JSON, and complete logs
are retained under `meshes/`, `results/`, and `logs/`.
Per-case convergence and mesh figures are saved in PNG, PDF, and SVG formats.
`geometric_certificate.json` and `.csv` independently bound the full-core
patch by covering-ball integrals and the off-core error by the potential
gradient. This comparison estimate uses no potential quadrature and checks
the predicted O(h^2) scaling independently of the optimized d_h integration.

The primary eigenvalue convergence diagnostic is `U_neumann-L_opt`, using
upper and lower values for the same finite-domain Neumann problem.
The Dirichlet-to-Neumann gap and comparison to the exact whole-space
one-centre value -1 include domain truncation effects, so they do not measure
the discretization rate indefinitely on a fixed domain. Local EOCs are
computed with the actual ratio of nominal h values; both h and h_max are
included in the output.

The original release tests passed 57/57 and the independent new numerical
tests passed 111/111. The latter cover ordinary-mesh agreement, local DOF
duality, mass positivity, stiffness nullspace, tiny translated/scaled cells,
dense eigenvalue references, singular quadrature, and all eight mesh reports.
The coarse one-centre higher-order quadrature repeat changes d_h by about
2.1e-5 relatively and the ground Neumann P1 eigenvalue by 2.1e-12.
Final checks of all eight runs are saved in `results/final_acceptance.json`.
Optimized-shift CECR equation residuals are below 3.82e-10; the largest P1
residual is 2.08e-9. The optional fixed-shift comparison reaches an equation
residual of 7.05e-7 (relative equation residual 3.15e-8) on the finest
two-centre mesh. It is recorded separately from the primary optimized-shift
convergence study. These residuals are numerical diagnostics rather than
verified eigenvalue-error estimates.

On the finest refinement, d_h has local order 2.003 (one centre) and 1.973
(two centres) in nominal h. The Neumann enclosure widths have orders 1.910
and 1.916 in nominal h, or 1.981 and 1.988 in measured h_max. The independent
geometric perturbation majorants have orders 2.023 and 2.019 in nominal h.

All reported arithmetic is Float64, including quadrature and eigenvalues,
as in the release. These are numerical convergence results; interval
arithmetic and verified eigenvalue bounds remain a separate certification
stage. This experiment does not modify the 3D cases.
