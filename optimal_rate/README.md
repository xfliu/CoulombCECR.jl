# Shrinking-core (optimal-rate) computations

This directory contains the mesh generators, drivers and results of the
computations on meshes whose singular core shrinks with the mesh parameter,
so that all correction terms decay at the rate O(h^2) predicted in the paper.
See [COMPLETE_CASE.md](COMPLETE_CASE.md) for the mesh construction,
numerical methods, output schema and reproduction details, and
[NOTES.md](NOTES.md) for the patch estimates and refinement details.

- 2D one- and two-centre problems: Cartesian cores of radius `1e-6*h^4`
  joined to the boundary by homothetic rectangular rings, `h = 0.8, 0.4, 0.2, 0.1`.
- 3D H2+: octant mesh with core radius `0.0015625*h^2`, homothetic cuboid
  shells, conforming longest-edge bisection capping `h_max <= h`, exact
  reflection to the full box; all eight parity sectors are solved,
  `h = 1, 2/3, 1/2`.

Reproduce from the repository root with `bash optimal_rate/run_complete.sh`
(meshes are regenerated by `gen_mesh.py`, `gen_mesh_3d.py` and
`refine_cap_3d.py`; they are not stored in git).

Key outputs:

- `results_complete/`: JSON results used in the paper (2D and capped 3D H2+).
- `convergence.csv`, `convergence.md`: convergence rates of the correction terms.
- `geometric_certificate.*`: geometry-only comparison estimates of `d_h`.
- `final_verification.json`: consistency checks of the reported values.
- `paper_assets_tools/make_assets.py`: generation of the paper tables and figures.

`INITIAL_2D_EXPERIMENT.md`, `results/` and `run_all.sh` record an earlier
fixed-epsilon 2D experiment and are kept for provenance. All arithmetic is
Float64; interval certification is a separate stage.
